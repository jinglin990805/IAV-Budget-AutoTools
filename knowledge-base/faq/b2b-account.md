# B2B 账号申请流程

## 背景

为项目员工创建客户端（如 VCTC、CARIAD）的 B2B 系统账号，使其能够访问客户的开发平台、提交工单等。

## 所需材料

1. 员工个人信息（姓名、邮箱、电话）
2. 项目信息（项目号、客户名称）
3. 客户方审批人信息
4. 安全培训记录（如适用）

## 申请步骤

1. 确认员工已加入项目且合同/PO 已生效
2. 联系客户方 IT 或项目接口人获取账号申请表
3. 填写申请表（员工信息 + 项目信息 + 权限级别）
4. 提交至客户方审批
5. 审批通过后通知员工激活账号
6. 记录账号信息到项目文档

## 注意事项

- 不同客户的 B2B 系统不同（VCTC 用 Volkswagen Group 系统，CARIAD 用 CARIAD 内部系统）
- 账号有有效期限制，通常与项目合同期一致
- 员工离职时需及时通知客户方注销账号
