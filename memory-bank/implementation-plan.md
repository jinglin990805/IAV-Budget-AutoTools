# Implementation Plan（无代码步骤）

## 总览

基于 grill-me 深度拷问后批准的工作台方案。分为 **5 个阶段**，每步可独立验证。遵循"一步一验证"原则。

---

## Phase 1: 修复核心计算准确度 ✅

### Step 1.1: PO Level 配额 PDF 解析
**目标**: 从客户 PO PDF 自动提取 Level 配额信息
**内容**: 新建 `po_pdf_parser.py`，用 pdfplumber 解析 VCTC PO PDF
**验证**: 解析 2607000312 → 180d×2100 + 85d×2260 + 464d×2460 = ¥1,711,540 ✓

### Step 1.2: 第三方工时 PDF 解析
**目标**: 从第三方人员工时 PDF 自动提取月度工时
**内容**: 新建 `timesheet_parser.py`，解析 `01_IAV TMS & WP/YYYYMM/` 下 PDF
**验证**: 2604 + 2605 目录 → 15 人匹配，文本型 PDF 工时正确提取 ✓

### Step 1.3: PO 分配算法重写
**目标**: 实现基于 Level 配额的分配算法
**内容**: 新建 `po_allocator_v2.py`，三源合并 + 姓名别名映射 + Level 配额消耗
**验证**: 加载 445 天工时，过渡月份拆分正确触发，输出 V2 报告 ✓

## Phase 3: 工作台 HTML 页面 (当前)

### Step 3.1: workbench.html 骨架

**验证**: 浏览器打开 → 左侧导航点击 → 内容区切换正确

**验证**: 打开首页 → 正确显示 🔴 overdue 和 🟡 upcoming 卡片

### Step 3.3: Python API 桥接
**目标**: 工作台能调用 Python 脚本

**验证**: 工作台点击"运行 PO 分配"→ API 返回结果

### Step 3.4: 搜索功能
**目标**: 全局搜索项目号、PO号、文档
